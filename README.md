### ex01 — Seletores CSS

Página informativa sobre os principais seletores CSS, construída a partir do exemplo fornecido. Inclui um formulário de contacto apenas demonstrativo.

Foram aplicados seletores universais, de elemento, de classe e de ID, bem como seletores de atributo e pseudoclasses para os estados de foco e passagem do rato. A folha de estilos está separada do HTML em `ex01/css/style.css`, para manter a estrutura e a apresentação organizadas.
